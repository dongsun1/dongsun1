#### 최근에 한 일

- 배포 직후 서비스 전체가 **60초**로 멈춘 장애에서, DB CPU가 멀쩡해 보이는 상태로

- 훅 하나 때문에 27개 페이지가 **빈 HTML**로 나가던 SSR 버그를 잡고,
  랜딩 TBT를 **19.4초 → 40ms**로 줄였습니다
- 관제 대시보드 **Lighthouse 30 → 90**, 공용 컴포넌트 라이브러리로 **중복 코드 40% 제거**
